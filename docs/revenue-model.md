# Revenue Model

## Tiers

### Free — ₹0/month
- **5 infographics per month**
- 3 niches
- Basic SVG templates
- Manual LinkedIn copy-paste
- Watermarked infographics

### Pro — ₹999/month (~$12)
- **100 infographics per month**
- All 9 niches
- LinkedIn auto-scheduling
- Brand templates (logo, custom colors)
- No watermark
- Agent trace viewer
- Priority queue (faster generation)

### Enterprise — ₹9,999+/month (~$120+)
- **Unlimited infographics**
- Team workspaces (up to 10 seats)
- Approval workflows
- Custom branding kit
- Multi-account LinkedIn publishing
- Dedicated support
- SLA guarantee
- Custom niche configuration
- API access

---

## Monetization Strategy

### Phase 1 (MVP): Individual Creators
Target: LinkedIn content creators, tech bloggers, developer advocates.
Channel: LinkedIn organic (post examples of AI-generated content), Product Hunt launch.

### Phase 2 (Month 3–6): Engineering Teams
Target: Developer advocacy teams at tech companies, bootcamps, online educators.
Use case: Auto-publish daily educational content under the company brand.

### Phase 3 (Month 6+): Agencies & Media
Target: Social media agencies managing tech clients.
Use case: White-label the platform, generate 10+ infographics/day per client.

## Unit Economics (Pro Tier)

| Item | Cost |
|---|---|
| GPT-4o per infographic | ~$0.08 |
| Claude per infographic | ~$0.02 |
| S3 storage per infographic | ~$0.001 |
| **Total AI cost per infographic** | **~$0.10** |
| Monthly cost at 100 infographics | **~$10** |
| Pro plan revenue | **₹999 (~$12)** |
| **Gross margin** | **~17%** |

> Margin improves significantly at Enterprise tier and with caching (same topic trending for multiple users).

## Key Metrics to Track

- Infographics generated per day
- Agent pipeline success rate (target: >95%)
- Time from "Generate" click to infographic ready (target: <60s)
- LinkedIn post engagement rate (impressions, likes, comments)
- Free → Pro conversion rate
- Monthly churn rate
